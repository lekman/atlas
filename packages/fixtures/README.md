# @atlas/fixtures

An invented consultancy (Ashgrove Consulting) and four invented clients
(Halcyon Labs, Kestrel Freight, Larchwood Studio, Meridian Bank), with a
scripted day of events that loops. `busyDataset` is the same dataset with
Halcyon Labs grown to a hundred generated items over six workstreams, to
show the map at the scale of a real client.

Every story, test and screenshot uses this. Add to it freely; never swap in
anything from real work. See
[No Client Content, Ever](../../.claude/rules/client-content.md).
